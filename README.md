# 物料管家 · 部署使用说明

电子协会物料管理系统：登记 / 出入库 / 智能配料 / 拍照识别 / 多端实时同步 / 离线可用。
纯前端 + 可选 Node 同步服务器，**零第三方依赖**，手机电脑平板都能用。

---

## 一、文件结构

```
hwms/
├── index.html          入口页面
├── style.css           全部样式
├── js/
│   ├── core.js         数据库(IndexedDB)、登录鉴权、通用工具

│   ├── pages_main.js   物料库 / 出入库 / 详情 / 拍照
│   ├── pages_stats.js  统计报表 / 历史追溯
│   ├── pages_admin.js  系统设置 / 同步配置 / AI 接入 / 主题 / 分类管理
│   └── pages_ai.js     智能配料 / 拍照识别 / AI 介绍
├── manifest.json       PWA 应用描述（安装到桌面用）
├── sw.js               Service Worker（离线缓存程序文件）
├── icons/              应用图标（192 / 512）
├── assets/             会徽等静态资源
├── 云端部署指南.md      ★ 免费托管到 Render，得到永久 https 网址（推荐阅读）

    └── 启动同步服务器.bat  Windows 一键启动
```

## 二、四种用法（按需选择）

### 方式 A：云端在线用 ★ 推荐，无需常开电脑
把整个系统免费托管到 Render 云平台，得到一个**永久 https:// 网址**，
把链接发给社员就能用，手机流量也能访问，数据实时同步。
**图文教程：见《云端部署指南.md》**（约 15 分钟，全程免费）。

### 方式 B：单机离线用（最简单）
直接双击 `index.html` 用浏览器打开即可。数据只存在这台电脑的浏览器里。
适合：个人电脑记账，不需要多人共享。

### 方式 C：局域网多人同步（需一台常开电脑）
1. 找一台常开的电脑（如协会服务器/值班机），装好 Node.js（nodejs.org 下载安装，一路下一步）。
2. 双击 `server/启动同步服务器.bat`，窗口里会打印出本机局域网地址，例如：
   `http://192.168.1.20:8787`
3. 协会 WiFi 下的所有人，手机/电脑浏览器打开这个地址就能用，数据实时同步。

### 方式 D：公网随时随地把玩（进阶，可选）
把方式 C 的电脑通过路由器"端口转发"或内网穿透工具（如 frp、花生壳）暴露到公网，
得到一个固定网址，校外也能访问。**注意**：务必设同步密钥（服务器设环境变量 `SYNC_KEY`），
或加一层反向代理的访问控制。

> **提示**：想要"公网 + 免常开电脑"，直接用方式 A 的云端部署更省心。

> **WiFi 信号差 / 哪天没了怎么办？**
> 本系统是"离线优先"设计：断网时照样能查库存、能登记出入库，
> 数据先存本机浏览器；恢复网络后 8 秒内自动把离线操作补传到服务器，不丢数据。
> 就算服务器永远没了，每台设备上的历史数据仍在，可随时导出 CSV 备份。

## 三、安装成"本地 App"（PWA）

用浏览器打开系统后：

| 设备 | 安装方法 |
|------|----------|
| Windows / Mac（Chrome/Edge） | 地址栏右侧的"安装"图标，或菜单 → 投放/安装 → 安装"物料管家" |
| 安卓（Chrome） | 菜单 → 添加到主屏幕 / 安装应用 |
| iPhone / iPad（Safari） | 分享按钮 → 添加到主屏幕 |

安装后就是独立窗口的 App 图标，和普通软件一样用，无需应用商店。
（注意：PWA 安装需要通过 http:// 访问；直接双击打开的 file:// 方式不支持安装，但仍可离线使用。）

## 四、AI 接入（智能配料 / 拍照识别）

进入 **系统设置 → AI 接入**：

### 1. 局域网 Ollama（免费、离线、无需 Key）
1. 在某台电脑装 Ollama（ollama.com），设置环境变量 `OLLAMA_HOST=0.0.0.0` 后启动，
   别人的设备才能访问它。
2. 拉模型：`ollama pull deepseek-r1:7b`（文本），拍照识别另需视觉模型
   `ollama pull qwen2.5vl:7b` 或 `ollama pull llava`。
3. 系统设置里填接口地址：`http://那台电脑的IP:11434/v1/chat/completions`，Key 留空。

### 2. 云端接口（有 Key）
- DeepSeek：`https://api.deepseek.com/v1/chat/completions`
- 智谱：`https://open.bigmodel.cn/api/paas/v4/chat/completions`（GLM-4V 系列支持拍照识别）

### 拍照识别说明
- **必须用支持"看图"的多模态模型**：qwen2.5vl / llava / GLM-4V。
  DeepSeek 等纯文本模型只能聊天，不能识别图片。
- 流程：拍照/选图 → 自动压缩 → AI 识别名称/型号/分类 → 一键带入新增物料表单，
  照片同时作为物料的第一张实物照。

## 五、日常备份

- **云端方式（推荐）**：数据自动在云和各设备之间互备；服务器清空会自动从设备补种回来。
  仍建议每月在物料库页导出一次 CSV 存协会网盘。
- **服务器方式**：所有数据都在 `server/data.json` 一个文件里，复制走就是完整备份。
- **单机方式**：数据在浏览器 IndexedDB 里，用物料库页的"导出 Excel"定期导出 CSV 即可。

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 打不开 8787 网址 | 同一 WiFi？防火墙放行 Node.js？服务器窗口是否还开着？ |
| 端口被占用 | 改启动脚本里的端口号，或关掉占用程序 |
| 同步灯一直是灰色 | 系统设置里检查同步地址是否可 ping 通，点"测试连接"看具体报错 |
| 提示"同步密钥不正确" | 服务器设了环境变量 `SYNC_KEY` 时，系统设置里的密钥要填一样的值 |
| 换了设备数据不全 | 登录后停留页面 10 秒等首次全量同步拉完 |
| 想清空重来 | 服务器：删掉 data.json 重启；单机：浏览器清站点数据 |
