# 物料管家 · 使用手册

电子协会物料管理系统：物料档案与模糊搜索 / 出入库与库存调整 / 库存预警 / 项目配料（AI 配料 + 嘉立创 BOM 导入 + 识别更正 + 历史项目一键再领）/ 拍照识别 / 统计报表 / 历史追溯与撤回 / 数据导入导出与全库备份 / 回收站 / 用户与权限管理 / 多端实时同步 / 离线可用。

纯前端（IndexedDB 本地库）+ 可选后端（Cloudflare Pages Functions + D1，或零依赖 Node 同步服务器），**零第三方依赖**，手机 / 平板 / 电脑都能用。

> 本文件讲**怎么用**。想了解**怎么部署**（免费托管到云端、多端同步后端）或**怎么改代码**（数据模型、同步算法、识别规则、安全加固），统一见 **[开发文档.md](开发文档.md)**。

## 一、功能总览

| 模块 | 能力 |
|------|------|
| 物料库 | 中文 / 拼音首字母 / 型号 / 丝印 / 别称 / 用途描述模糊搜索；按封装、存放位置、母/子分类、标签筛选；按编号、库存、单价、更新时间排序；新增 / 编辑（管理员或授权成员）；导出 CSV |
| 物料详情 | 档案信息、实物照片、AI 生成用途说明、全链路出入库时间线 |
| 出入库（无独立页面） | 物料库行尾"入 / 出"按钮、物料详情、库存预警（补货入库）、项目配料（一键出库）、拍照识别结果处均可弹窗登记；入库（采购 / 退回 / 捐赠）、出库（领用 / 消耗 / 报废）、库存调整（盘盈盘亏，管理员）；提交后弹出存放位置提示 |
| 库存预警 | 库存 ≤ 警戒线=告急、≤ 1.5 倍=偏低；出库后按近 90 天平均月消耗自动微调警戒线（有限幅与 7 天节流）；导出补货清单 |
| 项目配料 | 一句话需求 → AI 方案与物料清单；嘉立创 BOM 导入（csv / txt / xlsx / xls）→ 一键配齐；表头手动映射；**三槽识别更正**；AI 查找替代；导出取件 / 购买清单；历史项目一键再领 |
| 拍照识别 | 选图 / 手机拍照 / 电脑摄像头取景 / Ctrl+V 粘贴 / 拖拽；AI 认物后直接入库或出库，照片存入档案 |
| 统计报表 | 消耗排行、经费统计（管理员）、成员统计（管理员）、库存结构；统一时间范围筛选；导出 CSV |
| 历史追溯 | 多条件筛选、导出；**撤回 / 取消撤回**记录（冲销式，不改历史，库存自动回退） |
| 数据管理 | 物料 CSV 导入导出、全库备份（JSON）与恢复、回收站、示例数据、操作日志 |
| 用户管理 | 添加成员、改班级、临时授权、升降管理员、停用启用、重置密码（管理员） |
| 系统设置 | AI 接入（多配置按用途分配）、多端同步（**默认已按协会统一配好，成员不用填**）、界面主题、分类管理 |
| 使用手册 | 应用内「使用手册」页面，新手三分钟上手 |

## 三、四种用法（按需选择）

### 方式 A：云端在线用 ★ 推荐，无需常开电脑
把系统免费托管到 Cloudflare Pages，得到一个**永久 https:// 网址**，
把链接发给社员就能用，手机流量也能访问。
**部署步骤见《开发文档.md》的「十八、部署 A：Cloudflare Pages 静态托管」**（约 20 分钟，全程免费，不绑卡）。

> **注意**：纯静态托管只把网页放到云上，**不含同步服务器**——
> 每台设备的数据分别存在各自浏览器里，互相不通。
> 想多人共用一份数据，给同一个 Pages 项目补上「Pages Functions + D1」同步后端
> （免绑卡、免费、不休眠，主推，后端代码已内置在 `functions/` 目录），
> 步骤见《开发文档.md》的「十九、部署 B：多端同步后端」；或用方式 C 的局域网同步。
> 换设备时用"数据管理 → 全库备份 / 恢复"搬家。

### 方式 B：单机离线用（最简单）
直接双击 `index.html` 用浏览器打开即可。数据只存在这台电脑的浏览器里。
适合：个人电脑记账，不需要多人共享。

### 方式 C：局域网多人同步（需一台常开电脑）
1. 找一台常开的电脑（如协会服务器/值班机），装好 Node.js（nodejs.org 下载安装，一路下一步）。
2. 双击 `server/启动同步服务器.bat`，窗口里会打印出本机局域网地址，例如：
   `http://192.168.1.20:8787`
3. 协会 WiFi 下的所有人，手机/电脑浏览器打开这个地址就能用，数据实时同步。

### 方式 D：公网随时随地把玩（进阶，可选）
把方式 C 的电脑通过路由器"端口转发"或内网穿透工具（如 frp、花生壳）暴露到公网，
得到一个固定网址，校外也能访问。**注意**：公网暴露后任何知道网址的人都能读写数据，
建议加一层反向代理的访问控制（如 Basic Auth），或改用方式 A 的云端方案。

> **提示**：想要"公网网址 + 免常开电脑 + 多端共用数据"，推荐《开发文档.md》
> 「十九、部署 B」里的「Cloudflare Pages Functions + D1」方案（免绑卡、免费、不休眠，后端代码已内置）。
> 备选：把 server.js 单独部署到支持 Node 的云平台（如 Render，需绑卡），前端仍用 Cloudflare Pages。

> **WiFi 信号差 / 哪天没了怎么办？**
> 本系统是"离线优先"设计：断网时照样能查库存、能登记出入库，
> 数据先存本机浏览器；恢复网络后 8 秒内自动把离线操作补传到服务器，不丢数据。
> 就算服务器永远没了，每台设备上的历史数据仍在，可随时导出 CSV 备份。

## 四、安装成"本地 App"（PWA）

用浏览器打开系统后：

| 设备 | 安装方法 |
|------|----------|
| Windows / Mac（Chrome/Edge） | 地址栏右侧的"安装"图标，或菜单 → 投放/安装 → 安装"物料管家" |

## 五、AI 接入（多配置 · 按用途分配模型）

进入 **系统设置 → AI 接入**。可以**同时接入多个接口配置**，每个配置勾选它负责的用途：

| 用途 | 用在哪 | 模型要求 |
|------|--------|----------|
| 图片识别 | 物料库"拍照识别"：AI 看图认出元件 | **必须多模态**（qwen2.5vl / llava / GLM-4V 等） |
| 用途说明 | 新增物料时 AI 自动写用途描述 | 普通文本模型即可 |
| 智能配料 | 项目配料页：一句话说需求，AI 列物料清单 | 普通文本模型 |
| 项目领料 | 项目配料页：BOM 导入后 AI 从库存找替代、批量更正识别 | 普通文本模型 |

- 每一行配置后面有**"测试此配置"按钮**，填完先点它验证能不能通；
- 配置会自动折叠起来，点标题可展开修改；
- 可以点"设为默认"，未勾选用途时用默认配置兜底；
- **接口地址要填完整的 chat/completions 路径**，例如智谱填
  `https://open.bigmodel.cn/api/paas/v4/chat/completions`（只填到 `/v4` 或 `/api/paas` 会报错）。

### 免费本地方案（Ollama，离线无需 Key）
1. 在某台电脑装 Ollama（ollama.com），设置环境变量 `OLLAMA_HOST=0.0.0.0` 后启动，别人的设备才能访问它。
2. 拉模型：文本用 `ollama pull deepseek-r1:7b`；图片识别另需 `ollama pull qwen2.5vl:7b` 或 `ollama pull llava`。
3. 系统设置里填接口地址：`http://那台电脑的IP:11434/v1/chat/completions`，Key 留空。

### 云端接口（有 Key）
- DeepSeek：`https://api.deepseek.com/v1/chat/completions`
- 智谱：`https://open.bigmodel.cn/api/paas/v4/chat/completions`（GLM-4V 系列支持拍照识别）

> **AI 未启用也能用**：项目配料的"一句话配料"会自动回退到内置本地引擎（关键词模板匹配），
> 只是没有 AI 那么灵活；BOM 导入、出入库、查询等核心功能完全不依赖 AI。

## 六、项目配料（AI 配料 + BOM 一键配齐）

左侧菜单 **项目配料**，把原来的"智能配料"和"项目领料"合成了一个页面，三个视图：

### 6.1 首页：描述需求
输入一句话（如"做一个循迹小车"）→ 点 **AI 分析**（或按回车用本地引擎），AI 会给出多个不同思路的方案，切换标签查看，每个方案都自动匹配库存。

### 6.2 首页：导入嘉立创 BOM
点"导入嘉立创 BOM"，或**直接把 xlsx / csv / txt 文件拖进页面任意位置**（自动认表头）。
- 自动分出"库里有"和"库里没有"两堆：有的一键出库；没有的可点 **"AI 查找替代"**（分批串行问 AI，几十种约几分钟，耐心等）。
- 做一批几十个同样的项目时，填"本次要 N 份"，数量自动乘倍。
- **表头对不上？** 点"表头对不上？手动映射列"，手动指定数量列、名称列、型号列、标称值列、封装列、厂家型号列、立创编号列。

### 6.3 识别不准 → 三槽更正
BOM 导入后若某行认错了，点 **"手动/AI 更正"**。每一行有三个**相互独立**的更正槽：

| 槽位 | 怎么用 |
|------|--------|
| **AI 更正** | 勾选若干行 → 点"AI 更正（勾选行）"，AI 批量重认名称 / 类别 / 完整描述 |
| **手动输入更正** | 自己填名称、类别、型号、标称值、封装，右侧可对照原 BOM 信息 |
| **手动查找库更正** | 顶部显示原 BOM 信息，下面模糊搜索物料库，点选一个物料即可 |

三个槽各保留一条记录，可随时**切换生效**（选择）或**撤销生效**（结果仍保留），
当前生效的槽会标在物料行右上角；更正结果**随项目一起保存**，下次打开仍在。

### 6.4 历史项目
右上角 **历史项目**：搜索项目名 / 创建人，可打开、改名、设为公开或私密、删除（仅创建人或管理员）。
打开历史项目会：
- 恢复当时的 BOM 快照、更正记录、AI 问答；
- **按最新识别规则重跑一遍 BOM 识别**（自动修正旧版本的误判，已人工更正的行不会被覆盖）；
- 按当前库存重算配料状态，可直接"一键再领"。

### 6.5 导出与问答
- **导出取件清单**：普通成员需本人出库后可用，默认只导出点过"出库"的物料；管理员可追加"库里不够"的。
- **导出购买清单**：默认导出"库里没有"的，可勾选追加"库里不够"和"被代替"的。
- **AI 问答**：就着当前项目追问"怎么接线 / 代码怎么写 / 原理是什么"（对所有成员开放，无需先出库）。

## 七、拍照识别怎么用（物料库 → 右上角"图片识别"）

- 四种取图方式：**点选图片**、**手机调系统相机**拍、**电脑用网页摄像头**取景后点"拍照"、**Ctrl+V 粘贴 / 拖拽图片**进框；
- 识别后既能**出库**（库里有同款 → 直接出库），也能**入库**（库里有就加库存，识别照片自动存进档案实物照）；
- **"新增物料"入口只对管理员或被临时授权的成员显示**：未授权成员在识别结果里看不到该入口，只能给已有物料加库存，需要录入新元件时联系管理员（后端仍有一道 `Auth.can('manage')` 校验兜底）；
- 照片会自动压缩（长边 640）后再发送，省流量；识别历史保留近 24 小时，方便重复取用。

> **识别慢 / 报"速率限制(429)"？** 替代元件查找与批量更正是分批串行问 AI 的，模型响应慢时需要等待几分钟属正常；
> 429 会自动退避重试（10s / 20s / 30s），连续超限就稍等 1-2 分钟再点。单次请求 180 秒无响应会自动中止。

## 八、日常备份与初始化

- **云端 / 单机方式**：数据存在每台设备自己的浏览器里，设备之间互为独立；
  建议每月在"数据管理"页导出物料表 CSV，或用"导出全库备份（JSON）"。
  **也可以直接把 CSV / JSON 备份文件拖进页面**导入恢复。
- **自建同步服务器方式**：数据自动在服务器和各设备之间互备；服务器清空会自动从设备补种回来。
  `server/data.json` 复制走就是完整备份，仍建议每月导出一次 CSV。
- **回收站**：删除物料只是软删除（进回收站），删除人自己或管理员可**恢复**，仅管理员可**彻底删除**；
  彻底删除后，该物料的历史出入库记录仍保留可查。
- **数据管理里的几个按钮的区别**：
  - **载入示例数据**：导入 60 余种常用元件 + 5 个月模拟记录（编号已存在的自动跳过）；
  - **清空物料与记录**：只删业务数据（物料 + 出入库记录），保留账号、AI 配置等；
  - **所有数据初始化**：清空全部（含账号、AI 配置）恢复出厂，重置默认 admin/admin123——操作前会先提示备份。

## 九、常见问题

| 问题 | 处理 |
|------|------|
| 打不开 8787 网址 | 同一 WiFi？防火墙放行 Node.js？服务器窗口是否还开着？ |
| 端口被占用 | 改启动脚本里的端口号，或关掉占用程序 |
| 同步灯一直是灰色 | 系统设置里检查同步地址是否可 ping 通，点"测试连接"看具体报错 |
| 跨域被拦截（换域名调用接口） | 后端默认只放行同源；确需跨域时给 Pages 项目加环境变量 `ALLOWED_ORIGINS`（见《开发文档.md》「二十、部署常见问题」） |
| 换了设备数据不全 | 登录后停留页面 10 秒等首次全量同步拉完 |
| 想清空重来 | 服务器：删掉 data.json 重启；单机：浏览器清站点数据，或用数据管理里的"所有数据初始化" |
| AI 报"messages 参数非法 / 400" | 确认接口地址是完整的 `/v1/chat/completions` 路径 |
| AI 报"速率限制 429" | 接口套餐限流，等 1-2 分钟再试；高频操作（如整份 BOM 找替代）已自动串行重试 |
| 照片怎么加 | 物料表单里：选图 / 拍照 / Ctrl+V 粘贴 / 直接把图片拖进页面（识别弹窗开着就进识别，表单开着就进物料照片） |
| 位置看不到 | 普通成员只能看自己经手过（有过有效出入库）的物料位置，且查看后 10 分钟内有效 |
